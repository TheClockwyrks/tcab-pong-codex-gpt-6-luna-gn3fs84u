# Carom

Carom is a top-down paddle duel about reading the angle, adding spin, and banking shots around two fixed bumpers. Play solo against the computer or share a keyboard in local Versus. The first player to 11 points with a two-point lead wins.

## Install and run

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. To create the static production site in `dist/`, run:

```sh
npm run build
```

## Controls

- Player one: **W / S**
- Player two in Versus: **↑ / ↓**
- Solo: either player's movement keys control the left paddle
- Menus: **W/S** or **↑/↓**, then **Enter** or **Space**
- Pause or resume: **P** or **Escape**
- Mute: **M**
